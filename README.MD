## Project Overview

An Exploratory Data Analysis (EDA) project on the Superstore Sales dataset using Python, Pandas, and Matplotlib. The goal is to clean raw sales data, uncover business insights, and generate professional reports.

This project demonstrates end-to-end data analysis workflow:
- Data loading and exploration
- Data cleaning and preprocessing
- Feature engineering
- Business analysis and reporting
